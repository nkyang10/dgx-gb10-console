## A1 — 能量 / 成本（spark_hwmon，⏺ 低 effort）

**source of truth ＝ driver source（`spbm.c`），README 單位寫錯（mW/mJ 實則 .µW/µJ）**
```bash
# 動態發現 spbm hwmon（hwmonN 唔固定）
for d in /sys/class/hwmon/hwmon*; do [ "$(cat $d/name)" = "spbm" ] && echo $d; done
```

**Units（source 確認）**：power = **µW**、energy = **µJ**、temp = 毫°C。⚠️ 唔好除 1000 兩次。

**14 個 power channel（`power{1..14}_input`，µW）**：
| idx | label | 用途 |
|---|---|---|
| 1 | **sys_total** | 成部機 wall power（idle ~25W、peak ~240W）⭐ |
| 2 | soc_pkg / 3 cpu_gpu / 4 cpu_p / 5 cpu_e / 6 vcore | SoC 分域 |
| 7 | **dc_input** | DC/charger rail（可超 sys_total 當充電中）|
| 8 | **gpu** | GPU（≈ nvidia-smi power.draw，idle ~4.5W）⭐ |
| 9–14 | prereg/dla/pl1/pl2/syspl1/syspl2 | 其他 |

**（4 個 energy accumulator（`energy{1..4}_input`，累計 µJ）**：`pkg`、`cpu_e`、`cpu_p`、`gpu`。
> ⚠️ **每次 probe 要讀 `*_label` 確認 index**（hidden offset 會令 channel index 移位）；唔好 hardcode `power1`。

**kWh/day + cost**：
```
ΔE_µJ = (E1 − E0) wrap-safe mod 2^32*10^6   # u32 mJ accumulator ~48h@25W wrap
ΔJ    = ΔE_µJ / 1e6
avg_W = ΔJ / Δt_s
kWh/day = avg_W × 24 / 1000
cost_day($) = kWh/day × R      # R = $/kWh（config）
Cost NOW   = (power1_input/1e6)/1000 × R × 1h
```
> 用 **energy delta over ≥60s 窗**（firmware 100ms PID 令即時 power 振盪）； billing 用全日 ΔE。

**idle/active 分**：`active_W ≈ max(0, sys_total − idle_baseline)`（idle_baseline ≈ median ~25W）；或按 `engine_sleep_state` 分 bucket。
**Prometheus**：expose `status_energy_kwh_total`、`cost_usd_total`；`R` 當 config/annotation，唔做 label。

## A2 — Token 會計 / 成本（vLLM /metrics，🟡 低–中）

**source（已驗證 `loggers.py`）**：所有 token/prefix counter 有 `labelnames=["model_name","engine"]`；0.20.1/0.22.1 同名 set。
**counter 名**（0.20/0.22 modern；legacy `_total`/冇 prefix-cache）：
`vllm:prompt_tokens`、`vllm:prompt_tokens_cached`、`vllm:generation_tokens`、`vllm:prefix_cache_queries/_hits`、`vllm:request_success`。

**累積（per-model 近-day bucket）**：monotonic delta，`cur<prev`→restart（rate=0 + re-baseline `prev=cur`）。Write `token_usage(node,model,day,prompt_delta,gen_delta,cached_delta,prefix_hits,prefix_queries,req_success)`。**新一日 baseline current counters，唔 carry absolute offset。**

**per-model cost**：
```
cost_model = (Σday prompt_delta/1e6 × price_in) + (Σday gen_delta/1e6 × price_out)
# cache-discounted：input term 用 uncached_prompt = prompt_delta − cached_prompt_delta
```

**cache-hit 慳**：`saved_cost = cached_prompt_delta/1e6 × price_in`；`% saved on input = 100×cached/prompt`。可選用 energy-per-prefill-token 校準（med，可唔做 hard dep）。

**budget alert**：`budget_model_day/budget_day/budget_month`；gauge `cost_budget_ratio`，80% warn / 100% crit。⚠️ 唔好 auto-throttle/vLLM sleep（DGX awake-sleep bug）→ 淨讀 alert 先。

## A3 — 容量預測（Prometheus `predict_linear`，⏺ 低 effort，零 hand-roll）

> 主推 **Prometheus `predict_linear()`**（linear regression，built-in）。

### disk TTF
```promql
disk:node_filesystem_ttf_hours{mountpoint=~"/|/data.*"}
  = (1 - predict_linear(node_filesystem_avail_bytes[6h], 0)/node_filesystem_size_bytes)
    / clamp_min(-deriv(node_filesystem_avail_bytes[6h])/node_filesystem_size_bytes, 0)
- alert: DiskWillFillSoon   # warn H=4h
  expr: predict_linear(node_filesystem_avail_bytes{mountpoint=~"/|/data.*"}[6h],4*3600) < 0
  for: 5m
- alert: DiskWillFillNow    # crit H=6h
  expr: predict_linear(...[6h],6*3600) < 0   for: 5m
```
- 窗 **6–24h**（唔好用 1min spike）；`for:5m` debounce；`clamp_min` 防 div-0；flat slope＝TTF∞＝唔 alert。

### KV / UMA headroom（GB10 UMA：GPU headroom == 系統 RAM）
```promql
vllm:kv_cache_headroom = 1 - vllm:kv_cache_usage_perc              # 0..1
node:uma_mem_used_ratio = 1 - node_memory_MemAvailable_bytes/node_memory_MemTotal_bytes
- alert: KVCacheWillSaturate  expr: predict_linear(vllm:kv_cache_usage_perc[15m],1800) > 0.95  for:5m warn
- alert: UMAHeadroomExhausting expr: predict_linear(node_memory_MemAvailable_bytes[30m],6*3600) < 0 for:5m warn
```
> ⚠️ **唔好單靠 KV % 閾值 alert** —— high KV usage 喺 continuous batching 係正常+healthy（scheduler 會 preempt）。真正飽和信號＝KV 高 **+** `num_requests_waiting`>0 **+** preemption 升 **+** latency 差。建議組合 rule：
```promql
- alert: KVCachePressure  expr: vllm:kv_cache_usage_perc > 0.95 and (rate(vllm:num_preemptions_total[5m])>0) and (vllm:num_requests_waiting>0)  for:5m warn
```
> GB10 gotchas：MemAvailable 會隨 page cache 動（用 ≥30m–1h 窗）；vLLM weight load / sleep（weights_offloaded）會暫時拖低 MemAvailable→gate forecast 或用長窗。
