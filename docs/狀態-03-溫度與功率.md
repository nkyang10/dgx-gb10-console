# 狀態-03 · 溫度 與 功率（每節點）

> collector：`collectors/system.py` ｜ 優先級：⭐必備（溫度）／🟡可選（功率 rails）

---

## 溫度

```bash
cat /sys/class/thermal/thermal_zone*/temp    # 各 zone（毫°C，/1000 = °C）
sensors                                      # lm-sensors 讀 hwmon
cat /sys/class/hwmon/*/temp*_input           # 直接走 hwmon sysfs（更通用）
```

- Linux hwmon（SPBM 驅動 `antheas/spark_hwmon`）暴露 zones：**`tj_max`、`cpu_e_clu0/1`、`cpu_p_clu0/1`、`gpu`、`soc`**
- ⚠️ **`nvidia-smi soc`（v590+）係 Tegra-Linux only，唔喺 DGX OS 用**（CPU/SoC power 唔靠佢，用 spbm hwmon）
- 監測重點：接近 **96–97°C 節流線** 要警（EC/韌體更新後有節流問題討論）
- 規格理想操作溫度 5–30°C
- NIC ASIC 溫度（ConnectX-7）：`/sys/class/infiniband/*/device/hwmon/*`（sparktop/spark-smi）🟡

> 💡 **通用 walker**：唔好估 zone 名——掃 `/sys/class/thermal/thermal_zone*/temp` 全部，或用 `grep -H . /sys/class/hwmon/*/temp*_input`（sparktop 技巧，一次讀晒）。`tj_max/gpu/soc` 特別監。

## 功率

| 資料 | 點攞 | 單位 |
|---|---|---|
| GPU 即時功耗 | `nvidia-smi --query-gpu=power.draw,power.limit` | W（idle ~4.5W） |
| 整機/各 rail 功率（可選） | hwmon SPBM：`/sys/class/hwmon/*/name=="spbm"` → `power*_input`(µW)/`_label`；或 `lm-sensors 'spbm-*'` | W |
| 能量累計器 | spbm `pkg/cpu_e/cpu_p/gpu` | mJ/Wh |

- **spark_hwmon**（社群驅動）暴露 14 個 power channel（`sys_total`、`soc_pkg`、`cpu_gpu`、`cpu_p`、`cpu_e`、`gpu`、`dc_input`、`pl1/pl2/syspl1/syspl2`...）+ 4 個能量累計器
  - 峰值：系統 240W，GPU+CPU 140W
  - ⚠️ **NVIDIA 官方「無方法監控 CPU 功率」** —— spark_hwmon 係社群驅動，要自行安裝
  - 能量累計器比即時功率穩定（即時值有 100ms PID 振盪）
- 桌面機：只有 AC，冇電池

## ✅ 建議收（每節點）

- 溫度：`tj_max` / `gpu` / `soc` zone（`/sys/class/thermal` 或 hwmon）⭐
- GPU 功率：`nvidia-smi power.draw,power.limit` ⭐
- 整機功率 rails（`sys_total/gpu/dc_input`）：🟡 若裝咗 `spark_hwmon`（`lm-sensors 'spbm-*'` parse W line 即可，spark-mon 做法）；冇就全靠 nvidia-smi

## 🚨 相關警報

- **GpuTempCritical**：temp > 80（warn 92 / crit 96，低過 GB10 throttle line），`for:2m`
- **CPU/thermal**：soc/tj_max 接近 96–97°C 節流線
- PROCHOT（spbm）可選
