## systemd 服務 / process / 端口 / 版本

| 指標 | 指令 |
|---|---|
| 服務 active/enabled | `systemctl is-active <svc>` / `systemctl is-enabled <svc>`（batch：`systemctl is-active --quiet vllm docker sshd`） |
| 全部 unit 狀態 | `systemctl list-units --type=service --no-legend`（active/inactive/failed/dead） |
| Process | `pgrep -f vllm-serve` / `pgrep -f vllm` / `ps aux \| grep vllm` |
| 端口/LLM server | `ss -tlnp` / `ss -lntp \| grep :8000` / `lsof -i :8000 -sTCP:LISTEN` / `curl -s localhost:8000/v1/models` |
| 版本 | `dpkg -l \| grep vllm`、`docker --version`、`vllm --version`、`nvcc --version` |
| OS/kernel/uptime | `cat /etc/os-release`、`uname -r`、`uptime`、`nproc` |

> **Prometheus 正路**：node_exporter `systemd_unit_state{name="vllm",state="active"}`、`node_systemd_system_state`、`systemd_service_restart_total`。
> 「vLLM 真係 run 緊」最強信號 = `docker ps` 有 vllm container + `curl :8000/v1/models` 通（唔好淨靠 systemd，container 可以 active 但 model 死）。

## Docker / container

```bash
docker ps                                  # running containers（id,name,image,state,status）
docker stats --no-stream                   # container 即時用量
nvidia-ctk --version ; nvidia-ctk info     # NVIDIA Container Toolkit
```
- DGX Spark 通常用 Docker + NVIDIA Container Toolkit 行 vLLM。`docker ps` 見到 vllm = LLM server running。
- vLLM 容器自動偵測：`docker ps --filter name=vllm`（sparkscope 做法）→ 攞 published port。
